# puppetxr docs

| Doc | Read when |
|---|---|
| `architecture.md` | touching more than one layer, or adding a file |
| `style.md` | writing any code |
| `building.md` | changing CMake, dependencies, options |
| `config.md` | changing `puppetxr.json` keys, controls, env overrides |
| `testing.md` | adding tests, running CTS or sample apps |
| `openxr.md` | working in `oxr.cpp` / `oxr_vulkan.cpp` |
| `world.md` | working in `world.cpp`, rooms, raycasts |
| `room-format.md` | authoring or loading rooms |
| `compositor.md` | working in `render_vulkan.cpp`, `comp.cpp`, `ui.cpp` |
| `recording-format.md` | working in `rec.cpp` or reading recordings |
| `control-api.md` | using or extending the `puppetxr_*` API |
| `determinism.md` | touching math, time, event order |
| `samples.md` | running or fixing a sample app test |
| `meta-reports/` | bugs found in Meta's SDKs and samples, written up for Meta: `unity-mruk.md` (Unity MRUK, OVRPlugin), `unreal-samples.md` (Unreal samples, plugin, MRUK, Interaction SDK), `unreal-plugin-rendering.md` (near black content with alpha propagation, Vulkan foveation), `unity-movement.md` (Interaction SDK exit hang) |
| `body-tracking.md` | simulated body tracking |
| `face-tracking.md` | simulated face and eye tracking |
